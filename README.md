# 🎙️ Asisten Suara untuk Lansia

## 📖 Deskripsi
Sistem pengenalan suara berbasis AI untuk membantu lansia mengontrol perangkat di rumah menggunakan perintah suara sederhana.

## 🎯 Fitur
- ✅ Pengenalan perintah suara real-time
- ✅ Antarmuka ramah lansia
- ✅ 3 perintah utama: Buka Pintu, Nyalakan Lampu, Panggil Bantuan
- ✅ Feedback visual dan audio

## 🛠️ Teknologi
- Teachable Machine (Audio Model)
- TensorFlow.js
- HTML5 Speech Recognition API
- Vanilla JavaScript

## 🚀 Cara Menggunakan

### Instalasi
```bash
# Clone repository
git clone [URL_REPO]

# Masuk ke folder
cd asisten-suara-lansia

# Jalankan local server
python -m http.server 8000
```

### Penggunaan
1. Buka browser ke `http://localhost:8000`
2. Klik tombol mikrofon
3. Ucapkan salah satu perintah
4. Lihat hasil deteksi

## 🎤 Perintah yang Tersedia
1. **"Buka Pintu"** - Membuka pintu otomatis
2. **"Nyalakan Lampu"** - Menyalakan lampu ruangan
3. **"Panggil Bantuan"** - Memanggil bantuan darurat
